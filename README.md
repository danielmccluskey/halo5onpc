# Halo 5 Campaign on PC

A small hobby project to get the **Halo 5: Guardians campaign running on PC** using the existing Halo 5: Forge PC build.

At the moment I have the first two campaign missions running:

* **Osiris**
* **Blue Team**

There is still a lot to work out, but they're properly running and playable, which is further than I expected to get when I started messing with this.

## What is this?

The basic idea is to use the existing **Halo 5: Forge** PC version as the base and load the original Halo 5 campaign content into it.

This repository will contain a launcher and the work needed to connect the campaign files to the Forge build and launch the game.

I'm mainly making this because I want to **speedrun Halo 5 on PC**.

That's pretty much the goal.

I'm not particularly interested in bringing across multiplayer, matchmaking or the rest of the Xbox services. For now I just want to get the campaign working as well as I can.

## Current status

Very early.

Currently working:

* Halo 5: Forge PC build launches with campaign content
* **Mission 1 — Osiris**
* **Mission 2 — Blue Team**
* Campaign gameplay is running on PC

There will almost certainly be bugs, missing features and things which behave differently from the Xbox version.

I'll update this as I get further through the campaign.

## The launcher

The launcher is intended to make the process of starting the campaign version as simple as possible.

The eventual idea is roughly:

1. Have Halo 5: Forge installed.
2. Provide your own Halo 5 campaign files.
3. Point the launcher at them.
4. Let the launcher handle the files/configuration needed by the PC build.
5. Launch Halo 5.

The exact setup is still changing while I work through the campaign, so proper installation instructions will come once it's in a state I'm happy for other people to test.

## Game files

**Halo 5 game files are not included in this repository and will not be distributed by this project.**

You will need to provide your own copy of the required Halo 5 campaign data.

Please don't open issues asking me to upload or provide the game files.

This repository is just for the launcher, tooling and changes required to get that content working with the PC build.

## This isn't Halo 5: Reforged

This project is **not Halo 5: Reforged** and isn't connected to that project in any way.

This is a completely separate hobby project that I started because I wanted to see if I could get the original Halo 5 campaign running on PC.

## Why?

Mostly because Halo 5 is the awkward one if you want to play or speedrun the Halo campaigns on PC.
